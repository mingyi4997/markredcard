# MarkRedCard

将 Markdown 内容一键转换为小红书风格的图片卡片。

## 功能特性

- 📝 Markdown 编辑器，支持实时预览
- 🎨 6 套精美预设主题
- 📏 3 种卡片尺寸（3:4、1:1、4:3）
- 🔢 智能分页算法
- 📦 批量导出 PNG 图片
- 💾 自动保存草稿

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 技术栈

- React 18 + TypeScript
- Vite
- Tailwind CSS
- CodeMirror 6
- markdown-it
- Prism.js
- html-to-image
- Zustand
