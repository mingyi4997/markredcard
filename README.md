# MarkRedCard

将富文本内容一键转换为小红书风格的图片卡片。

🌐 **在线使用：** [markredcard.vercel.app](https://markredcard.vercel.app)

## 功能特性

- ✨ **富文本编辑器**：所见即所得的编辑体验，像 Word 一样轻松
- 🖼️ **图片支持**：直接粘贴、拖拽上传图片，可调整大小
- 🎨 **6 套精美主题**：经典白、暖阳橘、薄荷绿、星空蓝、樱花粉、高级灰
- 📏 **3 种卡片尺寸**：3:4（1080×1440）、1:1（1080×1080）、4:3（1080×810）
- 🎯 **样式增强**：自定义标题色块、引用竖线、图片横线等装饰元素
- 🔤 **多字体支持**：思源黑体、思源宋体、苹方、霞鹜文楷等 10+ 字体
- 🎨 **文字颜色/高亮**：自由调整文字颜色和背景高亮
- 🔢 **智能分页算法**：自动分页，防止内容截断
- 📦 **批量导出 PNG**：一键导出所有卡片为高清 PNG 图片（ZIP 打包）
- 💾 **自动保存**：本地自动保存，刷新不丢失

## 开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 技术栈

- **框架**: React 18 + TypeScript + Vite
- **样式**: Tailwind CSS
- **编辑器**: Tiptap (ProseMirror)
- **状态管理**: Zustand
- **图片导出**: html-to-image + JSZip
- **语法高亮**: Prism.js
- **部署**: Vercel
